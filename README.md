\# ✈️ Proyecto 1: TravelAgency (Arquitectura Monolítica) - Tingeso



Plataforma Fullstack desarrollada para la administración integral del flujo de negocio de una agencia de viajes. Este repositorio contiene la primera fase arquitectónica del sistema (Monolito), abarcando desde el desarrollo hasta el despliegue.



\## 🛠️ Stack Tecnológico y Fases del Proyecto

\* \*\*Backend:\*\* API RESTful construida con \*\*Spring Boot\*\* (Java) y \*\*PostgreSQL\*\*, implementando gestión de usuarios, catálogo de paquetes, motor de reservas con reglas de negocio y pasarela de pagos simulada.

\* \*\*Frontend:\*\* Interfaz de usuario dinámica desarrollada en \*\*React\*\* (En desarrollo).

\* \*\*DevOps \& Cloud:\*\* Contenedorización de la aplicación utilizando \*\*Docker\*\* y despliegue programado en la nube (Próximamente).



Desarrollado como parte de la formación en Ingeniería de Ejecución en Computación e Informática en la Universidad de Santiago de Chile (USACH).
